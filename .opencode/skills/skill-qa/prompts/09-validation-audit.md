## Task

Determine whether the skill has specific validation steps.

Look for:
- Type checking
- Unit tests
- Build checks
- Linting
- Runtime behavior checks
- Regression checks
- Edge case tests
- Schema validation
- Security checks
- Final diff review

Do not accept generic instructions like "make sure it works."

## Required Output Format

### Current Validation Behavior
Describe what validation the skill currently requires.

### Weak or Generic Checks
List vague validation instructions that should be made specific.

### Missing Validation Steps
List concrete validation steps that are absent but should be present for this type of skill.

### Recommended Validation Checklist
Provide a numbered checklist of specific validation steps appropriate for this skill's purpose.
